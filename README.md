## About me

I'm a software developer in İstanbul with 3.5+ years of professional experience. I like owning software end to end: the architecture, the code, the tests and the release.

At **OGZA Technology** I set up layered architectures for Flutter and Kotlin codebases, wrote most of the critical modules myself, planned the technical work, reviewed merge requests and ran App Store and Google Play releases. The work I'm proudest of:

- **Halleder, a fintech super app (Tam Finans).** I built its mobile architecture and core codebase: Clean Architecture and DDD with Cubit / Bloc, reusable internal packages, deep links, Keystore / Keychain and AES / RSA data protection, and unit, widget and integration tests in GitLab CI.
- **CebePOS payment SDK (Akbank).** A Kotlin app that validated the SDK's payment flows: MVVM with Coroutines / Flow and Jetpack Compose, hardened with SSL pinning, R8 obfuscation and root / emulator checks. I fixed the pentest findings and published the artifacts with Maven.
- **Poyo LMS (Mavi Connect · Arçelik).** A white-label learning platform where one Flutter codebase produces a separate app per brand. I built every module, from video lessons and e-books to exams and messaging.
- **Web work.** A Vue.js and TypeScript ERP with role-based access, and an Ionic / Angular LMS I upgraded and moved to Okta sign-in over OAuth 2.0 / OpenID Connect with PKCE.

On my own I built **[Recipely](https://recipely.net/about)** end to end: iOS, Android and web apps from one React Native / Expo codebase, a Node.js / Express / Prisma / PostgreSQL backend running in Docker on Oracle Cloud, and AI features on Gemini and Groq that write recipes, moderate content, estimate nutrition and turn Instagram videos into recipes. It's live on the [App Store](https://apps.apple.com/us/app/recipely/id6787391255) and [Google Play](https://play.google.com/store/apps/details?id=com.recipely.app).

I'm not tied to one stack. I've shipped Dart, Kotlin, TypeScript and JavaScript, and used Python and ABAP on real projects; I learn whatever the problem needs. I build with AI agents every day, and keep the result honest with strict types, architecture checks, tests and CI.
